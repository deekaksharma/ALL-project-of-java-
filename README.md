# Java Lab - All Experiments & Final Project

A comprehensive collection of Java laboratory experiments covering GUI programming (Swing), MVC architecture, Database Connectivity (JDBC), Networking (Sockets), Distributed Systems (RMI), Java Enterprise Web (Servlets & JSP), and a complete multi-module enterprise e-commerce platform (**ShopSphere**).

### 🛍️ Comprehensive Capstone Project: [ShopSphere](./Project%20-%20ShopSphere/)

**ShopSphere** is an end-to-end multi-module enterprise e-commerce application demonstrating the full breadth of Java technologies:

* **`shopsphere-core`**: Core business domain, models, DAOs, service layer, security, validation utilities, and unit tests.
* **`shopsphere-desktop`**: Admin desktop application built with Java Swing for product, order, category, and customer management.
* **`shopsphere-network`**: Low-level TCP socket client/server system with custom protocols for real-time inventory synchronization.
* **`shopsphere-rmi`**: Distributed RMI service enabling remote clients to manage inventory securely.
* **`shopsphere-web`**: Dynamic web storefront with JSP, JSTL, Servlets, session management, filters, and shopping cart/checkout flows.

## 🚀 Getting Started

### Prerequisites
- **Java Development Kit (JDK)**: JDK 11 or higher (JDK 17+ recommended)
- **Apache Maven**: 3.8+ (for Maven-based modules)
- **MySQL Server**: (for JDBC & ShopSphere database)
- **Apache Tomcat**: 9 or 10 (for Servlets and JSP web apps)

### Running Experiments
- **Swing / Standard Java Experiments (1, 2, 4, 5)**:
  Compile and run using standard `javac` and `java` commands or via your IDE.
- **Web / Maven Experiments (6, 7 & ShopSphere)**:
  Navigate to the respective module directory and run:
  ```bash
  mvn clean install
  ```
